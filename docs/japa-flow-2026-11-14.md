# Japa procedure and counting flow — 14 November 2026

The native flow replaces the disconnected goal-changing controls with:

1. Select the full mantra name. Read pūrvāṅga in the landscape reader, then explicitly start counting.
2. Record Japa using the large +1 button or add a positive batch of completed repetitions. Undo reverses the last action, including a whole batch. Daily and cumulative totals change by exactly the same accepted amount. Undo is single-action and cannot be repeated on the same action. Targets are read-only here and remain configured in Settings.
3. Continue to uttarāṅga. Read it in landscape, then explicitly finish. If below the daily target, confirm finishing with the recorded count unchanged.
4. The completed summary retains all counts. Continue counting reopens the count stage; it does not reset or fill the counter.

Stages persist per profile/mantra/day in the encrypted Japa store. Returning from the reader refreshes the screen; reading does not automatically assert that a religious procedure is complete. Switching mantras preserves each saved stage and count. Daily rollover clears daily count, stage and undo metadata while retaining cumulative total. Existing saved counts are not reset by this redesign.

The footer keeps the next/back procedure actions visible above navigation. The counting panel is available only during the count stage; there is no target editing or destructive reset action. The current day/target and cumulative/Sankalpa totals are shown separately from stage progress. Stage progress describes the procedure, not an inferred bead count.

Dashboard completion is now read per mantra. Finishing one mantra cannot colour every other Japa tile complete. The legacy overall day flag is synchronized only when all user-selected mantras are finished, and never auto-fills totals. Existing global day flags are not treated as evidence of individual mantra completion; old counts remain intact.
