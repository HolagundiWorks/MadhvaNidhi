# MadhvaNidhi Privacy Policy

Last updated: 14 November 2026

MadhvaNidhi is developed and published by VISWABHIRAM D HOLAGUNDI, an individual
developer based in Hosapete, Karnataka, India. It is an offline-first Panchanga
and Madhva devotional reader.

## Information stored on your device

The app does not require an online account. A local Sadhak profile may contain
your name, gotra, pravara, rashi, nakshatra, birth details, marital status, Veda
shakha, Matha and diksha/Japa preferences. Profile details are used for local
personalisation, including Sankalpa text.

Practice records, Japa counts/targets, reading position, alarms, and app
preferences are stored locally. Profile/vault records use encrypted local
storage. Other app preferences and practice logs are local app data; this policy
does not claim that every preference file is encrypted.

You can create a passphrase-protected profile backup using the Backup tab.
Portable profile backups use AES-GCM. You choose where to save these files;
the app does not upload the user vault to a developer-operated cloud service.

## Network use

When a live Panchanga source is selected and internet is available, the app may
request Panchanga information from the official source. For the current Sri
Raghavendra Swamy Matha feed, that source is `srsmatha.org`. The source server
can receive normal connection information, such as IP address, request time,
requested calendar date and user agent. Its server-side handling is governed by
its own practices. Local profile fields are not included in the date request.

If live information is unavailable, the app uses locally calculated values and
identifies the source/fallback in the app.

## Advertising, analytics and sharing

The current app has no advertising or third-party analytics SDK. The developer
does not sell local profile or practice records and does not operate a cloud
profile-sync service. Backups you choose to export are under your control.

## Permissions

Internet access supports optional Panchanga retrieval. Notification, vibration,
wake-lock and boot-completion permissions support alarms/reminders and app
behaviour. You can control notification permission in Android settings.
The app does not request contacts or device-location permission.

## Retention and deletion

Local app records remain until you clear app storage or uninstall the app.
Exported backup files can remain in the location you selected after uninstall;
delete those files separately if you no longer need them. There is no
MadhvaNidhi online account or developer-hosted profile to delete.

## Children

MadhvaNidhi is a general-audience devotional reference app and is not designed
specifically for children.
